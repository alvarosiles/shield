Acerca de Shield

Shield es una plantilla de bóveda digital personal construida con HTML5, CSS3 y JavaScript ES6 puro, sin frameworks ni backend. Esta es una versión demo: no almacenes información sensible real sin cifrado. Consulta el README para conocer cómo extender la arquitectura con cifrado, autenticación y sincronización segura.
