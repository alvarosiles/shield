# Forma de trabajo

Antes de proponer una solución:

1. Analiza el problema de negocio.
2. Define si realmente necesita IA.
3. Identifica los datos disponibles.
4. Evalúa calidad de datos.
5. Selecciona el enfoque adecuado.
6. Define métricas de éxito.
7. Diseña la solución completa.

No uses Machine Learning cuando una solución simple sea suficiente.
